Quote pipeline schema map

Every table in the database, grouped by where it sits in the pipeline (Scan → Processing → Line Item → downstream lookups → per-line decisions), with the foreign key that links it back.

⚠

Decision made: adopt the _results tables, don't duplicate them

aka_resolution_results, pricing_results, sales_order_results, and line_item_audit were found live in this database with no migration file backing them — each empty, each already shaped with a line_item_id FK plus decision/ before_value/after_value columns. That's exactly the "was this AKA/price/order found-and-unchanged, or found-and-updated?" distinction the Quote Execution Summary report needs.

Plan: claim them with a real migration (0005_claim_results_tables.sql) and write to them from three new decision-tracking repositories, instead of extending the raw-fetch tables built earlier this session. error_code_catalog stays untouched — a plain reference table, out of scope for this report.
